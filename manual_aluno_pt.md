# Manual do Aluno - MIPS (Mapa Interativo de Salas)

## 📚 Bem-vindo ao MIPS

O MIPS é uma plataforma digital desenvolvida para auxiliar na gestão e navegação das salas do IPS. Este manual vai ajudá-lo a utilizar todas as funcionalidades disponíveis para alunos.

---

## 🔐 Como Fazer Login

1. Aceda à página de login do MIPS
2. Introduza o seu **email** registado
3. Introduza a sua **password**
4. Clique no botão **"Entrar"**
5. Será redirecionado para a página principal de aluno

> **Nota:** Se tiver problemas de acesso, contacte o administrador do sistema.

---

## 🗺️ Funcionalidades Disponíveis

### 1. Ver Mapa Interativo

Esta funcionalidade permite visualizar o mapa das salas do IPS.

**Como usar:**
1. Clique em **"Ver Mapa"** no menu superior
2. O mapa do andar 2 será exibido automaticamente
3. Use as **setas laterais** (◀ ▶) para navegar entre andares:
   - **Seta direita:** Vai para o Andar 3
   - **Seta esquerda:** Volta para o Andar 2
4. **Passe o rato** sobre qualquer sala para ver informações adicionais
5. Os **marcadores azuis** indicam a localização das salas

**Características do Mapa:**
- Visualização interativa dos andares 2 e 3
- Marcadores de sala com tooltips informativos
- Navegação simples entre andares
- Design responsivo (funciona em telemóvel e tablet)

---

### 2. Pesquisar Sala e Abrir Mapa

Esta é a forma mais rápida de encontrar uma sala específica.

**Como usar:**
1. Clique em **"Procurar"** no menu superior
2. No campo **"Selecione a Sala"**, digite o nome/número da sala (ex: F210, F315)
3. Aparecerá uma lista de sugestões enquanto escreve
4. Clique na sala desejada ou pressione **Enter**
5. O mapa abrirá automaticamente no andar correto
6. A sala escolhida ficará **destacada em amarelo** para fácil identificação

**Dicas:**
- Pode escrever apenas parte do nome (ex: "F2" mostra todas as salas do andar 2)
- O sistema ajusta automaticamente para maiúsculas/minúsculas
- Salas disponíveis: F210, F211, F212, F212A, F212B (Andar 2) e F311, F313, F315, F317, F319, F314A, F316, F318, F320 (Andar 3)

---

### 3. Informações da Conta

Visualize os seus dados de conta e perfil.

**Como usar:**
1. Clique em **"Informações da Conta"** no menu superior
2. Verá as seguintes informações:
   - **Tipo de conta:** Aluno
   - **Nome completo**
   - **Email registado**
   - **Descrição das funcionalidades** disponíveis para alunos

---

### 4. Sair da Conta

**Como usar:**
1. Clique em **"Sair"** no menu superior
2. Será redirecionado para a página de login
3. A sua sessão será encerrada com segurança

---

## 📱 Utilização no Telemóvel

O MIPS é totalmente responsivo e funciona perfeitamente em dispositivos móveis.

**Menu no Telemóvel:**
1. Clique no **ícone do menu** (☰) no canto superior direito
2. O menu expandirá mostrando todas as opções
3. Selecione a funcionalidade desejada
4. O menu fecha automaticamente após a seleção

**Dicas para Telemóvel:**
- Use os dedos para ampliar o mapa (pinch-to-zoom)
- As setas de navegação são facilmente clicáveis
- Todos os quadrados ficam centralizados para melhor visualização

## ❓ Perguntas Frequentes

**P: Posso reservar salas?**
R: Não, apenas os professores têm permissão para fazer reservas de salas.

**P: Como sei que sala tenho aula?**
R: Use a funcionalidade "Procurar" para encontrar rapidamente a localização da sua sala.

**P: O mapa funciona offline?**
R: Não, precisa de estar conectado à internet para aceder ao MIPS.

**P: Posso ver alertas de segurança?**
R: Não, esta funcionalidade está disponível apenas para membros da segurança.

**P: Esqueci-me da minha password, o que faço?**
R: Contacte o administrador do sistema para recuperar o acesso.
