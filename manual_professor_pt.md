# Manual do Professor - MIPS (Mapa Interativo de Salas)

## 📚 Bem-vindo ao MIPS

O MIPS é uma plataforma digital desenvolvida para auxiliar na gestão das salas do IPS. Este manual vai ajudá-lo a utilizar todas as funcionalidades disponíveis para professores, incluindo a gestão de reservas de salas.

---

## 🔐 Como Fazer Login

1. Aceda à página de login do MIPS
2. Introduza o seu **email** registado
3. Introduza a sua **password**
4. Clique no botão **"Entrar"**
5. Será redirecionado para a página principal de professor

> **Nota:** Se tiver problemas de acesso, contacte o administrador do sistema.

---

## 🗺️ Funcionalidades Disponíveis

### 1. Ver Mapa Interativo

Visualize o mapa das salas do IPS com todos os espaços disponíveis.

**Como usar:**
1. Clique em **"Ver Mapa"** no menu superior
2. O mapa do andar 2 será exibido automaticamente
3. Use as **setas laterais** (◀ ▶) para navegar entre andares
4. **Passe o rato** sobre qualquer sala para ver:
   - Nome da sala
   - Horas reservadas (se aplicável)
   - Último alerta de segurança
5. Os **marcadores azuis** indicam salas disponíveis
6. Os **marcadores vermelhos** indicam salas com alertas ativos

**Informações no Tooltip:**
- **Nome da sala**
- **Horas reservadas hoje:** Lista de horários ocupados
- **Último alerta:** Informação sobre abertura/fecho da porta

---

### 2. Procurar Sala

Encontre rapidamente qualquer sala no mapa.

**Como usar:**
1. Clique em **"Procurar"** no menu superior
2. Digite o nome/número da sala (ex: F210, F315)
3. Selecione a sala da lista de sugestões
4. O mapa abrirá automaticamente no andar correto
5. A sala escolhida ficará **destacada em amarelo**

---

### 3. Gestão de Reservas

Visualize, crie e cancele reservas de salas. Esta é uma das funcionalidades mais importantes para professores.

**Como usar:**
1. Clique em **"Salas Livres"** no menu superior
2. Verá uma tabela com todas as suas reservas:
   - **Sala:** Número da sala reservada
   - **Professor:** Seu nome
   - **Data:** Data da reserva
   - **Hora:** Horário reservado
   - **Ações:** Botões para cancelar

**Cancelar uma Reserva:**
1. Localize a reserva na tabela
2. Clique no botão **"Cancelar"** (ícone ❌)
3. Confirme a ação na janela de confirmação
4. A reserva será removida imediatamente

**Informações Importantes:**
- Pode ver todas as suas reservas ativas
- As reservas são organizadas por data e hora
- Só pode cancelar as suas próprias reservas
- Não é possível editar uma reserva (deve cancelar e criar nova)

---

### 4. Fazer Nova Reserva

Reserve uma sala para uma data e horário específicos.

**Como usar:**
1. Clique em **"Pedir Sala"** no menu superior
2. Preencha o formulário com:
   - **Sala:** Selecione da lista (ex: F210, F315)
   - **Data:** Escolha a data desejada
   - **Hora:** Selecione o horário (formato 24h, ex: 14:00)
3. Clique em **"Reservar"**
4. O sistema verificará:
   - Se a sala existe
   - Se a data é válida
   - Se já existe uma reserva para essa sala nesse horário
5. Receberá uma confirmação ou mensagem de erro

**Regras de Reserva:**
- Deve ser um horário válido (8h-20h)
- Não pode reservar horários já ocupados
- A data deve ser futura ou hoje
- Uma sala só pode ter uma reserva por horário

**Mensagens Possíveis:**
- ✅ "Reserva efetuada com sucesso!"
- ❌ "Já existe uma reserva para esta sala neste horário"
- ❌ "Por favor preencha todos os campos"
- ❌ "Sala inválida"

---

### 5. Informações da Conta

Visualize os seus dados de conta e perfil.

**Como usar:**
1. Clique em **"Informações da Conta"** no menu superior
2. Verá as seguintes informações:
   - **Tipo de conta:** Professor
   - **Nome completo**
   - **Email registado**
   - **Descrição das funcionalidades** disponíveis

---

### 6. Sair da Conta

**Como usar:**
1. Clique em **"Sair"** no menu superior
2. Será redirecionado para a página de login
3. A sua sessão será encerrada com segurança

## 📱 Utilização no Telemóvel

O MIPS é totalmente responsivo e funciona perfeitamente em dispositivos móveis.

**Menu no Telemóvel:**
1. Clique no **ícone do menu** (☰) no canto superior direito
2. O menu expandirá mostrando todas as opções
3. Selecione a funcionalidade desejada
4. O menu fecha automaticamente após a seleção

**Dicas para Telemóvel:**
- Use os dedos para ampliar o mapa
- As tabelas de reservas têm scroll horizontal
- Todos os formulários são otimizados para touch
- Os quadrados ficam centralizados para melhor visualização

## ❓ Perguntas Frequentes

**P: Quantas reservas posso fazer?**
R: Não há limite, mas deve respeitar os horários disponíveis e não fazer reservas duplicadas.

**P: Posso reservar uma sala para outra pessoa?**
R: Não, as reservas são sempre registadas em seu nome.

**P: Posso editar uma reserva existente?**
R: Não diretamente. Deve cancelar a reserva antiga e criar uma nova.

**P: Como sei se uma sala está livre?**
R: Veja o mapa e passe o rato sobre a sala para ver as horas reservadas.

**P: Posso fazer reservas recorrentes (semanais)?**
R: Não, cada reserva deve ser feita individualmente.

**P: Até quando posso cancelar uma reserva?**
R: Pode cancelar a qualquer momento antes do horário reservado.

## 📊 Boas Práticas

✅ **Planeie com antecedência:** Reserve salas com tempo suficiente
✅ **Cancele reservas** que não vai usar para libertar a sala
✅ **Verifique disponibilidade** no mapa antes de reservar
✅ **Confirme os detalhes** (sala, data, hora) antes de submeter
✅ **Faça logout** quando terminar, especialmente em computadores partilhados

---

## 🔔 Notificações

O sistema **não** envia notificações ou lembretes automáticos de reservas. É sua responsabilidade:
- Lembrar-se das suas reservas
- Consultar regularmente a lista de reservas
- Cancelar reservas que não vai usar
