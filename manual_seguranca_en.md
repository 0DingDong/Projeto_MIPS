# Security Manual - MIPS (Interactive Room Map)

## 📚 Welcome to MIPS

MIPS is a digital platform developed to assist in managing IPS rooms. This manual will help you use all features available for security members, including real-time alert monitoring.

---

## 🔐 How to Login

1. Access the MIPS login page
2. Enter your registered **email**
3. Enter your **password**
4. Click the **"Login"** button
5. You will be redirected to the main security page

> **Note:** If you have access issues, contact the system administrator.

---

## 🗺️ Available Features

### 1. View Interactive Map

View the room map with real-time security indicators.

**How to use:**
1. Click **"Ver Mapa"** (View Map) in the top menu
2. The 2nd floor map will be displayed automatically
3. Use the **side arrows** (◀ ▶) to navigate between floors
4. **Hover your mouse** over any room to see:
   - Room name
   - Last registered alert
   - Door status (open/closed)
5. **Markers** indicate room status:
   - **Blue:** Room without active alerts
   - **Red:** Room with open door (active alert)

**Tooltip Information:**
- **Room name**
- **Last alert:** Date, time, and alert type
- **Current status:** Door open or closed

---

### 2. Search Room

Quickly find any room on the map.

**How to use:**
1. Click **"Procurar"** (Search) in the top menu
2. Type the room name/number (e.g., F210, F315)
3. Select the room from the suggestion list
4. The map will automatically open on the correct floor
5. The chosen room will be **highlighted in yellow**

---

### 3. Active Alerts 🚨

Monitor all open doors in real-time. **This is the main feature for security.**

**How to use:**
1. Click **"Alertas"** (Alerts) in the top menu
2. You will see a list of all active alerts:
   - **Sala (Room):** Room number with open door
   - **Mensagem (Message):** Alert description
   - **Aberto em (Opened at):** Date and time door was opened
3. List updates **automatically every 5 seconds**
4. If no alerts: "Nenhum alerta ativo" (No active alerts)

**Real-Time Notifications:**
- **Alert sounds:** Plays automatically when there's a new alert
- **Toast notifications:** Appear in the top right corner of screen
- **Automatic updates:** No need to reload page

**Important:**
- Alerts are automatically generated by ESP32 sensors on doors
- When a door closes, alert moves to history
- Notifications work **even without clicking "Alertas"** - starting automatically on login

---

### 4. Search Alerts by Room

Check the complete alert history for a specific room.

**How to use:**
1. Click **"Procurar"** (Search) in the top menu
2. Type the room name (e.g., F315)
3. Select the room from the suggestion list
4. You will see a table with all alerts for that room:
   - **Sala (Room):** Room number
   - **Aberto (Opened):** Opening date and time
   - **Fechado (Closed):** Closing date and time
5. Table shows historical alerts (already closed doors)

**Usefulness:**
- Check room usage patterns
- Investigate specific incidents
- Audit access to sensitive rooms
- Security reports

---

### 5. Alert History

View complete history of all alerts registered in the system.

**How to use:**
1. Click **"Histórico de Alertas"** (Alert History) in the top menu
2. You will see a table with all historical alerts:
   - **Sala (Room):** Room number
   - **Aberto (Opened):** Opening date and time
   - **Fechado (Closed):** Closing date and time
3. List is ordered from most recent to oldest
4. Table updates **automatically every 10 seconds**

**Difference between Alerts and History:**
- **Alertas (Alerts):** Currently open doors (active)
- **Histórico (History):** Doors that have been closed (completed)

---

### 6. Account Information

View your account and profile data.

**How to use:**
1. Click **"Informações da Conta"** (Account Information) in the top menu
2. You will see:
   - **Account type:** Security
   - **Full name**
   - **Registered email**
   - **Description of features** available

---

### 7. Logout

**How to use:**
1. Click **"Sair"** (Logout) in the top menu
2. You will be redirected to the login page
3. Your session will be securely closed

## 🔔 Notification System

MIPS has an advanced notification system for security:

### Toast Notifications
- Appear automatically in the **top right corner**
- Red color for critical alerts (door open)
- Duration: 7 seconds (closes automatically)
- Shows room and alert type

### Alert Sound
- **Beep** at 800Hz for 200ms
- Plays automatically when there's a new alert
- Helps draw attention even if not looking at screen

### Automatic Polling
- System checks for new alerts **every 3 seconds**
- Works in background, even without alerts page open
- Starts automatically on security login

---

## 🔌 ESP32 Sensor Integration

MIPS is integrated with physical sensors on room doors:

**How It Works:**
1. ESP32 sensors are installed on doors
2. When a door **opens**, sensor sends alert to server
3. Alert appears immediately in "Active Alerts" list
4. Receives sound and visual notification
5. When door **closes**, sensor sends confirmation
6. Alert moves to "Alert History"

**Technical Information:**
- Sensors communicate via HTTP GET
- Endpoint: `receber_alerta.php`
- JSON data stored in: `historico_alertas.json` and `historico_alertas_pending.json`

## ❓ Frequently Asked Questions

**Q: Do notifications work if I'm in another section?**
A: Yes! Automatic polling works in background throughout security page.

**Q: Can I disable alert sounds?**
A: Not currently, but you can mute browser/device.

**Q: How often does the system check for new alerts?**
A: Every 3 seconds automatically.

**Q: What happens if I miss a notification?**
A: You can always check "Active Alerts" to see all open doors.

**Q: Can I delete alerts from history?**
A: No, history is permanent for audit purposes.

**Q: Do alerts work 24/7?**
A: Yes, sensors are always active and sending data.

**Q: Can I export alert history?**
A: Not directly through interface, contact administrator.

## 🚨 Emergency Procedures

**When receiving an alert:**
1. ✅ Immediately check room on map
2. ✅ Note time and exact location
3. ✅ If necessary, physically go to location
4. ✅ Record any irregularities
5. ✅ Wait for alert to move to history when door closes

**Suspicious Alerts:**
- Doors open outside normal hours
- Multiple openings in short time
- Doors that stay open too long

- Check internet connection
- Reload page

**Problem: Sounds don't play**

- Check device volume
- Some browsers block automatic audio
